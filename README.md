# NATO-alfabet

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-rein033-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/rein033)

Leer het NATO-spellingsalfabet (Alfa, Bravo, Charlie) of het Nederlandse (Anton, Bernard, Cornelis). Zet tekst om, laat hem voorlezen en oefen met een quiz.
*Learn the NATO phonetic alphabet (or the Dutch one): convert text, hear it spoken and practise with a quiz.*

**Gebruik hem:** [uselesssite.nl/nato-alfabet](https://uselesssite.nl/nato-alfabet/)

- NATO-alfabet en het Nederlandse spellingsalfabet
- Tekst omzetten naar spelwoorden, kopiëren en laten voorlezen
- Quiz: letter naar woord (typen of kiezen) en woord naar letter
- Score, reeks en de letters die je het vaakst fout hebt
- Werkt ook op je telefoon

Alles gebeurt in je browser, er gaat niets naar een server.

Onderdeel van de gratis, open-source tools op [uselesssite.nl/tools](https://uselesssite.nl/tools/).

## Ontwikkelen

Gewoon HTML, CSS en JavaScript, zonder build-stap. Open `index.html` via een willekeurige webserver.
`base.css` en `base.js` zijn gedeeld met de andere tools; de tool zelf zit in `app.js` en `style.css`.
